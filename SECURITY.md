# Security policy

Please report suspected Tinify for Mac vulnerabilities privately to
`support@larsenutvikling.no` with the subject `Tinify for Mac security`.

Include the app version and build, macOS version, processor architecture and a
minimal reproduction. Do not send API keys, account or device tokens, private
keys, Keychain exports, real customer images or sensitive filenames/paths.

Do not open a public issue until the report has been investigated and public
disclosure has been coordinated.
