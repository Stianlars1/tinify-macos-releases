# Tinify for Mac 1.0.13

Tinify for Mac 1.0.13 keeps a linked Mac connected when an account refresh is delivered more than once.

## Highlights

- Account refresh now recovers from duplicate delivery or a lost response without unlinking the Mac.
- Desktop Impact continues syncing after recovery without repeating or inflating statistics.

## Improvements

- Refresh requests use the server's explicit sender-bound protocol and one bounded recovery attempt.
- Credential updates are serialized across Tinify processes so stale work cannot delete newer account state.

## Fixes

- Fixed `refresh_reuse_revoked` disconnecting a legitimate Mac after concurrent refresh delivery.
- Fixed a stale process being able to clear credentials saved by a newer process.

## Privacy and security

- Every account refresh remains bound to this Mac's Ed25519 device key.
- Tokens, proofs and account data remain excluded from logs and Desktop Impact payloads.

## Compatibility

- Requires macOS 14 or later on an Apple silicon Mac.
- Existing linked accounts, settings, presets, automations, activity and Impact state carry over.

## Known issues

- The public Intel build remains withheld until separate physical Intel and filesystem validation are complete.
- Clean-machine VoiceOver, keyboard-navigation and existing-install background-agent migration remain separate release gates.
