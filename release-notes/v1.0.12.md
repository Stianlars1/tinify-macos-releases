# Tinify for Mac 1.0.12

Tinify for Mac 1.0.12 standardizes dash punctuation across the app and supporting product text.

## Highlights

- Replaced Unicode dash and minus characters with the ordinary ASCII hyphen.
- The completed Impact sync message now uses the readable form `sent - never`.

## Improvements

- App copy, accessibility text, comments, tests, release guidance, and design references now follow one punctuation rule.
- Repository instructions explicitly prevent Unicode dash characters from returning in future changes.

## Fixes

- Removed the em dash visible in the empty Desktop Impact sync state.
- Normalized attached parenthetical dashes to use spaces around the ASCII hyphen.

## Privacy and security

- This release does not change processing, account authority, Desktop Impact data, network boundaries, retention, or billing.
- Images, filenames, paths, pixels, embedded metadata, and file-access permissions remain outside account sync.

## Compatibility

- Requires macOS 14 or later on an Apple silicon Mac.
- Your settings, presets, automations, linked account, activity, and Impact state carry over.

## Known issues

- The public Intel build remains withheld until separate physical Intel and filesystem validation are complete.
- Clean-machine VoiceOver, keyboard-navigation, and existing-install background-agent migration remain separate release gates.
