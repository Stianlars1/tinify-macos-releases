# Tinify for Mac 1.0.10

Tinify for Mac 1.0.10 improves the reliability of first-launch setup and adds a privacy-bounded, anonymous signal that helps us understand app adoption.

## Highlights

- After a successful first launch, Tinify can send one anonymous installation report to help us understand how the app is adopted.
- First-launch reporting happens after the main window is ready, so it does not block opening the app.

## Improvements

- A first-launch report is kept safely when the Mac is offline and retried later.
- The first-launch request uses a strict, versioned contract so malformed reports are rejected before they leave the app.

## Fixes

- Fixed corrupt saved first-launch state preventing a report from being queued correctly.

## Privacy and security

- First-launch reporting is enabled only in signed production releases and remains disabled in Debug builds.
- This release does not change image processing, presets, automations, or existing account settings.

## Compatibility

- Requires macOS 14 or later on an Apple silicon Mac.
- Your settings, presets, automations, linked accounts, and existing activity carry over.

## Known issues

- The public Intel build remains withheld until separate physical Intel and filesystem validation are complete.
- Clean-machine VoiceOver, keyboard-navigation, and existing-install background-agent migration remain separate release gates.
