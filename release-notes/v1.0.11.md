# Tinify for Mac 1.0.11

Tinify for Mac 1.0.11 makes account Impact synchronization complete a pending backlog in one run and reports more accurate processing statistics.

## Highlights

- One Sync action now continues through the activity that was already waiting when the run began, using safe bounded requests instead of stopping after 100 events.
- Impact shows how many measured events have synced and how many remain on the Mac.
- Linking an eligible account starts the same serialized Impact sync automatically.

## Improvements

- New processing records include the exact tools that were applied: Compress, Resize, Crop, and Convert.
- Combined workflows count one processed file in the total while each applied tool is counted in its own statistic.
- Historical records remain included without guessing which tools were used.

## Fixes

- Fixed large local Impact queues advancing by only one batch per synchronization run.
- Fixed cancellation being presented as a failed sync even though the exact pending batch remained safe for retry.

## Privacy and security

- Image files, pixels, filenames, paths, embedded metadata, and file-access permissions still remain outside account sync.
- Account networking remains in Tinify.app; the background processing agent still has no account credentials or network path.
- Request size, replay protection, device binding, pacing, retention, and explicit local deletion remain enforced.

## Compatibility

- Requires macOS 14 or later on an Apple silicon Mac.
- Your settings, presets, automations, linked accounts, existing activity, and pending Impact queue carry over.

## Known issues

- The public Intel build remains withheld until separate physical Intel and filesystem validation are complete.
- Clean-machine VoiceOver, keyboard-navigation, and existing-install background-agent migration remain separate release gates.
