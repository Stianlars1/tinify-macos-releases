# Tinify for Mac 1.0.9

Finder optimization now handles large folders quickly, keeps active work readable, and finishes with a clear summary of the space saved.

## Highlights

- Right-click a folder in Finder to optimize the supported images inside it, including subfolders when enabled in Settings.
- Finder runs now show active files first and finish with a compact receipt. Waiting and completed files stay available in expandable sections, and any problems open automatically with a clear explanation.
- Finder optimization now replaces originals by default. Choose copy or Trash behavior under Settings → Finder before starting a run if you want a different destination.

## Improvements

- Large Finder selections are queued safely in bounded chunks while keeping one stable total and live progress for every file.
- Tinify processes up to ten images at once on capable Macs while using a smaller memory-aware width on lower-memory machines.
- Completion summaries distinguish optimized files, already-optimal files, successful results without savings, and files that need attention.

## Fixes

- Fixed long maintenance pauses during large batches; the verified 3,087-image run completed without a progress gap over one second.
- Fixed Finder progress appearing stuck at zero or 500 files while older jobs were already running.
- Fixed replace-original runs that reported saved bytes without writing the optimized result back to the source file.
- Fixed background processing registration on current macOS versions and made blocked registration failures actionable.
- Fixed Quick Action handoff and confirmation failures that could return no work, lose the selected folder, or reject a folder-sized enqueue.

## Compatibility

- Requires macOS 14 or later on an Apple silicon Mac.
- Settings, presets, automations, linked accounts, and existing activity carry over.

## Known issues

- The public Intel build remains withheld until separate physical Intel and filesystem validation are complete.
- Clean-machine VoiceOver, keyboard-navigation, and existing-install background-agent migration remain separate release gates.
