# Tinify for Mac 1.0.8

Right-click "Optimize with Tinify" now shows a live progress window, respects your output setting, and batches finish about twice as fast.

## Improvements

- Choosing "Optimize with Tinify" in Finder now opens a compact Tinify window that lists each file and shows its progress, then the space saved - instead of the generic macOS progress bar that appeared late.
- The Finder action now follows the output setting you chose in Tinify. If you set "Replace original," it optimizes in place instead of leaving a second copy next to the original.
- Batches process more images at once. The number of images in flight now follows your Mac's performance cores and memory, so a folder of screenshots finishes in roughly half the time on a capable Mac while smaller Macs are unchanged.

## Fixes

- The "Optimize with Tinify" icon in the Finder menu follows the system appearance again - white in Dark Mode, black in Light Mode - instead of staying black in both.
- Running the Finder action while Tinify was closed no longer opens the main window alongside the progress window.

## Compatibility

- Requires macOS 14 or later on an Apple silicon Mac.
- Settings, presets, automations, and linked accounts carry over.

## Known issues

- The public Intel build is withheld until separate physical Intel and filesystem validation is complete.
- VoiceOver and full keyboard-navigation coverage for some Optimize controls is still being improved.
