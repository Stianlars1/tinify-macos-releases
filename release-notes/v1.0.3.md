# Tinify for Mac 1.0.3

Batches finish faster: images now compress in parallel, and the queue finally looks as busy as it is.

## Improvements

- Batches process up to four images at once instead of one at a time, scaled to your Mac's hardware. Same engine, same results — just less waiting.
- The processing indicator actually spins while a file is being worked on, and stops the moment it finishes. Respects Reduce Motion.
- The batch header now reads naturally while several files run at once ("Processing 4 images · 1 done").

## Fixes

- Two files with the same name processed at the same time can no longer collide; the second file gets a numbered name exactly as before.
- Updating the app restarts the background helper more reliably.
- Queued items in Activity no longer show a processing indicator before they actually start.

## Compatibility

- Requires macOS 14 or later on an Apple silicon Mac.
- Settings, presets, automations, and linked accounts carry over.

## Known issues

- The public Intel build is withheld until separate physical Intel and filesystem validation is complete.
- VoiceOver and full keyboard-navigation coverage for some Optimize controls is still being improved.
